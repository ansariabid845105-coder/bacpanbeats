BachpanBeats — responsive nostalgic music website

Responsive layout is designed for mobile phones, tablets, laptops and desktop PCs.

Preview locally:
1. Extract this ZIP.
2. Open the BachpanBeats folder in VS Code.
3. Open index.html in a browser (or use Live Server).

To deploy:
Upload the contents of the BachpanBeats folder so index.html is at the deployment root.

Music:
Add audio files only when you have the right to host and stream them. Update script.js with the correct relative paths.

AdSense:
The existing AdSense code snippet is retained. Keep the website live and wait for Google's review; approval is not guaranteed.
